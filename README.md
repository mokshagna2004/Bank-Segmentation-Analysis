# Bank Segmentation Analysis

A SQL-based banking analytics project using a simulated dataset to analyze customer behavior, transactions, account activity, and regional performance.

## Objective

Extract meaningful banking insights such as:

* High-value customers
* Transaction trends and spending behavior
* Dormant and single-product accounts
* City and regional performance

## Tools & Technologies

* PostgreSQL
* pgAdmin
* SQL — CTEs, Joins, Aggregations, Window Functions
* PostgreSQL functions for data simulation

## Dataset

The project uses three core tables:

* `customers`
* `accounts`
* `transactions`

## Key Analysis

* Customer spending and credit inflows
* Monthly and yearly transaction trends
* Most active accounts
* Dormant accounts
* Transaction service usage
* City-wise and regional performance
* Highest spender by city

## Key Learnings

Strengthened SQL skills in `JOIN`, `GROUP BY`, `FILTER`, `DATE_TRUNC`, `CASE WHEN`, CTEs, and window functions while working with financial data.
